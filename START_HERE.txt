CLUB GENESIS GMS - 最初に読むファイル

このシステムで使うもの:
1. ログイン: Firebase Authentication
2. データ保存: Cloud Firestore
3. 公開: Firebase Hosting または Vercel

本番データと開発データ:
1. 本番サイトは dailyClosings に保存します。
2. dev環境とローカルは dailyClosings-dev に保存します。
3. 本番と開発の締めデータは相互に表示されません。
4. ログインユーザーは共通です。
5. 画面に本番または開発の表示があります。

POS締めデータ連携:
1. POSからGMS Firebaseへ直接送信しません。
2. POSの過去営業履歴で「GMS取込JSON」を出力します。
3. GMSの「POSファイル取込」でJSONを選択して取り込みます。
4. 取り込んだデータは dailyClosings または dailyClosings-dev に保存されます。
5. shopClosings / shopClosings-dev は使用しません。
6. 正式取込はUTF-8 JSONのみ対応します。CSVは確認用です。

ローカルで開くとき:
1. index.htmlを直接ダブルクリックしないでください。
2. file:/// ではFirebaseログインが動かない場合があります。
3. フォルダ内の起動.batまたはlocal-server.cjsを使ってください。
4. URLは http://localhost:4173/index.html です。

Firestoreルール:
1. firestore.rules をFirebase ConsoleまたはFirebase CLIで反映してください。
2. dailyClosings / dailyClosings-dev の作成・更新はログイン済みの accounting または shop ロールだけ許可します。
3. POS端末からGMS Firestoreへ直接書き込ませるルールは不要です。

動作確認:
1. POSで営業終了済みの日付からGMS取込JSONを出力します。
2. GMSにaccountingユーザーでログインします。
3. POSファイル取込でJSONを選択して取り込みます。
4. 受信データに営業日・総売上・伝票件数が表示されることを確認します。
5. 内容確認後に確定します。
